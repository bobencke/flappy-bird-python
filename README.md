# Flappy Bird Python

Flappy Bird game in Python, developed in 2024 as a personal project while following a YouTube tutorial.

## Features

- Bird jump with gravity-based movement, rotation, and wing animation
- Collision detection using Pygame masks
- Pipes with random gap positions and an endlessly scrolling floor
- Score tracking
- Object-oriented structure with separate classes for the bird, pipes, and floor

## Getting Started

Requirements: Python 3 and [Pygame](https://www.pygame.org/).

```bash
git clone https://github.com/bobencke/flappy-bird-python.git
cd flappy-bird-python
pip install pygame
python base.py
```

Press the space bar to jump.
